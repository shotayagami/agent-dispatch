# rules

エージェントの協調と判断範囲の決まりの、サンプルです。`~/.claude/rules/` に写すと、Claude が自動で読み込みます。Codex に読ませるときは、`~/.codex/AGENTS.md` から参照します。

- `agent-collaboration.md`: 着手の宣言、ブランチと作業ツリー、受け渡しの形式、ラベルによる依頼
- `agent-autonomy.md`: 人に確かめずに進めてよい範囲を決める 3 段階

`bin/agent-dispatch` はこれらのファイルを読みません。コメントで参照しているだけで、動作には影響しません。ホスト名、ログイン名、本番の定義は置き換えてあるので、自分の環境に合わせて書き直してください。
